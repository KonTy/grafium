Grafium is AGPL-3.0. Before distributing the native AAR in a release, retain the
upstream and transitive license texts/notices and provide corresponding source
under the applicable licenses; this provenance inventory is not a substitute
for those distribution obligations. No voice model is bundled or downloaded
automatically. Each voice package must carry license metadata and a checksummed
license artifact; its own license, not the runtime's license, governs the model.

Android voice packages use sherpa-vits-v1 with converted Piper/VITS ONNX metadata
and hash-verified espeak-ng-data files; raw Piper ONNX is not compatible. The
shared Rust package/ONNX validator runs before an installation is published,
before selecting a voice, and before constructing the native speech engine.
Missing validation support or rejected metadata is an explicit error, never a
fallback to an unchecked model or system/cloud TTS. This validation-only JNI
adapter does not prepare or modify the canonical EPUB narration queue.
