# Help - Flashcards

Create a card by writing `Question :: Answer` in one block. Add a tag such as
`#biology` to group cards into a study topic.

Open **Flashcards** from the sidebar to review due cards. Grafium schedules
reviews using spaced repetition.

**Import pack** accepts ordinary Anki `.apkg` decks and IQ-marked JSON packs.
An `.apkg` containing `grafium-iq.json` opens the assessment path instead of
recall review. IQ-marked packs appear in a separate section even when no
spaced-repetition cards are due.

Assessments save submitted answers, withhold explanations until the result,
and do not change repetition schedules. Unnormed packs report a reasoning
score, not IQ. Norm-backed estimates use the modern deviation-IQ formula,
`IQ = 100 + 15z`, only for eligible, unpractised attempts. Pack-supplied norms
are not independently verified. See [[Help - IQ Assessments]] for conditions,
limitations and the pack format; F1 opens that help while assessing a pack.
