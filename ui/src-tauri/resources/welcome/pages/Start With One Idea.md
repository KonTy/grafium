Press **Enter** for another block. Use **Tab** to indent and **Shift+Tab** to outdent. **Shift+Enter** keeps a new line inside the same block. Type `/` to explore the editor's commands.

The **classic block editor is the default**. While you edit a block's source, surrounding blocks can stay rendered. It supports selecting and navigating across blocks, but it is not one continuous text-editing surface.

To try cross-block text selection, use the page header's **Experimental continuous editor** button. This is an opt-in choice for that page. Switch back with **Classic block editor**.
