# Help - Tasks

Tasks are blocks beginning with `TODO`, `DOING`, `DONE`, or `CANCELED`.
You can add `SCHEDULED` and `DEADLINE` dates, then use the Tasks view and SQL
queries to find work across the graph.

The open-task list loads first. Activity heatmaps, completion history, and flow
metrics stay collapsed—and are not queried—until you choose **Show activity**,
so a long history does not delay current work.

## Review similar tasks with ASK

In Chat, choose **Ask / act > Group open tasks**, or ask "Group my TODOs by
similarity and flag possible duplicates." Review and edit the proposal before
pressing **Apply**.

This creates a separate reference page grouped by topic, using the original
task block IDs. It does not duplicate TODOs, move tasks between their notes,
change the Tasks query's order, or mark tasks completed. Possible duplicates
are suggestions for your review, not automatic deletions. Follow a reference to
inspect its source before making a decision.

Group assignments reflect the analyzed snapshot. Rerun ASK when the original
tasks change substantially; the saved grouping does not silently recluster.
See [[Help - Chat]] for cancellation, scope, privacy, source-change checks,
and the related-topic and rough-note drafting actions.
