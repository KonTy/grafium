A graph is a folder-backed workspace. This Welcome Graph is one workspace; your own graph can begin empty and grow around your interests.

1. Open the graph menu.
2. Choose **New Graph**.
3. Give it a name and choose a folder you control.
4. Let Grafium create the graph structure, then write one note.

Use the graph menu to switch between workspaces. Grafium remembers the selected graph; creating your own does not require deleting this example.

Start with a small question rather than importing everything at once. [[Start With One Idea]] is a pattern you can reuse, not a mandatory template.

Before moving important material, read [[Your Files]] for backup boundaries and [[Imports And Media]] for supported import formats.
