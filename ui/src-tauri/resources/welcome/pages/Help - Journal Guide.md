# Help - Journal Guide

The Journal is the fastest place to capture a thought. Each dated page is made
from blocks: small pieces of writing that can be nested, linked, searched, and
turned into work.

## Capture and edit

1. Open **Journal** from the sidebar.
2. Type in a block. Press **Enter** for another block.
3. Press **Tab** to nest a block and **Shift+Tab** to outdent it.
4. Press **Shift+Enter** to add a line inside one block.
5. Leave a block to see rendered Markdown; click it again to edit the source.

Try this:

```text
The best idea from today is ...
TODO Turn this idea into a page
[[A page I want to remember]]
```

Blocks keep their identity, so outlines can be reordered, folded, copied, and
selected without flattening the journal into one large text field.

## Links and connections

Write `[[Dinner ideas]]` to connect to a page. Following a missing link can
create the page. Use **Ctrl+L** / **Cmd+L** to list links for the current page,
then open **Graph** to see the surrounding network.

## Time and tasks

- Journal pages are dated automatically.
- Use **Go to time** or the calendar to jump to another day.
- Use the timestamp command to insert the current local date and time.
- Begin a block with `TODO` to show it in Tasks.
- Add `SCHEDULED` or `DEADLINE` when a task needs a date.
- Use **Ctrl+Shift+P** / **Cmd+Shift+P** and search `time`, `timestamp`, or
  `journal` to discover related commands.

## Find your way around

- **Ctrl+K / Cmd+K** searches the graph.
- **Ctrl+L / Cmd+L** lists page links.
- **Ctrl+Shift+B / Cmd+Shift+B** toggles the right reference panel.
- **Ctrl+Shift+P / Cmd+Shift+P** opens commands.
- **F1** opens contextual help.

## Import books and media

Use **Import media** for images, audio, and video. Assets stay beside the graph
and can be referenced from Markdown. Use **Import books** for a directory of
books; the imported pages can be searched and annotated from the right panel.
Open [[Imports And Media]] for the longer explanation.
