# Projects

A project needs a purpose, a next action, and somewhere to record what changed. It does not need a complicated system.

The fictional [[Projects/Observatory Night]] connects a plan with learning about the night sky:

- [[Projects/Observatory Night/Plan]] — nested, editable work.
- [[Projects/Observatory Night/Log]] — decisions and observations.
- [[Projects/Tasks And Dates]] — states and date pickers.
- [[Projects/Task Dashboard]] — open work, queried live.

Try completing one task in the plan, then return to the dashboard to see the remaining work.
