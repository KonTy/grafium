# Projects / Observatory Night / Log

An example decision log can be short:

- **Decision:** start with binoculars rather than assembling the full kit.
  - **Reason:** a quick setup leaves more time to learn the sky.
  - **Trade-off:** less magnification.
- **Observation to record later:** what was visible, the conditions, and what remained uncertain.
  - A sketch can be more honest than a confident label.
- **Next question:** how do aperture and magnification differ?
  - Investigate [[Space/Telescopes]] and [[Space/Light]].

Link the log from [[Projects/Observatory Night/Plan]] so decisions remain close to the work. Put time-specific notes in [[Journal And Calendar]] and link back to this project.
