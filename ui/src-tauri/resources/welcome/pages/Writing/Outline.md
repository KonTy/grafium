An outline is a draft you can rearrange. Indent supporting detail under the idea it explains, collapse a branch to focus, and reorder blocks when the story changes.

- A short explanation of an orbit
  - Begin with an everyday question.
    - What changes when an object moves sideways while falling?
  - Separate the two ingredients.
    - Gravity changes the direction of motion.
    - Sideways motion carries the object onward.
  - End with a sketch and one check-your-understanding question.

Try moving the sketch earlier in this outline. Then collapse the first branch and work on the conclusion.
