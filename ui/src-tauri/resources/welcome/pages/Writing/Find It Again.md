# Writing / Find It Again

## A name, not a filing decision

Pages give ideas a reusable address. Press **Ctrl/Cmd+K** for global search: search for **sideways motion** to find a block by its content, or **Orbits** to jump by title. **Ctrl/Cmd+Shift+K** searches within the current page. Full-text search indexes your graph; it is separate from optional AI chat.

## Namespaces

Slash-separated page titles make a hierarchy. These are three real pages:

- [[Space]]
- [[Space/Orbits]]
- [[Space/Orbits/Gravity]]

The corresponding Markdown lives in nested folders under `pages/`. Browse the hierarchy or use breadcrumbs to move to a parent. A namespace organizes names; explicit page links still express relationships between ideas.

## Shortcuts back to your work

Favorite a page you return to often. Linked references show the blocks pointing at the current page; block references point at one specific statement. Try both in [[Writing/Connections]].

A collection is another kind of route: [[Learning/Reading Shelf]] gathers an ordered selection without moving the source notes.
