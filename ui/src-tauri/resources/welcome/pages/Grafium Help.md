# Grafium Help

Press **F1** anywhere in Grafium to open help for the screen you are using.

If a help page opens empty, make sure you are using the built-in **Welcome**
graph. F1 opens these pages there so help is available even while you work in a
separate graph.

## Everyday navigation

| Action | Shortcut |
| --- | --- |
| Contextual help | `F1` |
| Command palette | `Ctrl+Shift+P` / `Cmd+Shift+P` |
| Search | `Ctrl+K` / `Cmd+K` |
| Current page links | `Ctrl+L` / `Cmd+L` |
| Right reference panel | `Ctrl+Shift+B` / `Cmd+Shift+B` |

The command palette is also the best way to discover commands for dates,
timestamps, imports, themes, graphs, and navigation. Keyboard symbols follow
your platform: `Ctrl` is `Cmd` on macOS.

## What Grafium stores

Grafium is a local-first graph of Markdown pages and journals. Blocks remain
individual pieces of knowledge, links connect pages, and graph views visualize
those links. Images, audio, video, books, flashcards, tasks, and reading notes
are all ways to work with the same local graph.

These pages are normal Grafium pages and can be edited.
