# A historical date example

This seeded example marks the date of the Apollo 11 lunar landing. It is a public historical prompt, not your diary, and it carries no task or reminder.

- **Question:** what makes an observation different from an explanation?
  - [[Space/Light]] concerns the signal reaching an observer.
  - [[Space/Orbits]] concerns a model of motion.
- **Practice:** write one sentence distinguishing those ideas.

Use [[Journal And Calendar]] to navigate to another past or future day, then return to today.
