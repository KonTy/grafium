The runtime runs in a data: document with a unique opaque origin, not privileged
app-origin srcdoc. Its bridge checks source window and per-mount random token.
The small trusted bootstrap accepts the bundled runtime once from the parent
frame using a source-window and nonce-checked postMessage transfer.
Book markup is sanitized before being assigned to a nested srcdoc, with a
script-src 'none'/network-denying CSP. Outer CSP allows only embedded runtime,
local blob resources, bundled classic data workers, and inline layout styles. Frame sandbox excludes
top navigation, popups, forms, downloads, and storage access.

Reflowable EPUB/FB2/MOBI/AZW3 use versioned CFIs; protected/DRM books are unsupported.
Fixed-layout EPUB can render but passage annotations are explicitly unavailable.
PDF.js is used directly with canvas/text layers, page/rectangle annotations and
local fonts/CMaps/WASM. PDF document JavaScript, actions, forms, and embedded links
are not executed or rendered. Image-only PDFs have no selectable text unless an
embedded text layer exists. Platform WebView behavior must be validated separately
from Chromium tests, especially older WebKit and opaque-origin worker support.
